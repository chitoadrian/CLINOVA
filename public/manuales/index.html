Estado real

La clínica utiliza React, IndexedDB o SQLite y un proyecto Supabase real para sincronización clínica. Cada cuenta tiene un espacio propio. Jeshua puede exportar coordinación y directorio; Adrian y Matias, el resumen de su área y los informes de pacientes; Wilson, el resumen contable. Los cargos, cobros y gastos de Wilson permanecen locales y aún no se comparten por Supabase.

CLINOVA no está programada en C++. Las herramientas C++ de Microsoft se usaron para compilar el instalador Windows de Tauri.
