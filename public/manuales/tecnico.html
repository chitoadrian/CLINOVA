Manual técnico

CLINOVA usa React + TypeScript; IndexedDB en Web y SQLite en Tauri. El intercambio clínico emplea Supabase Auth, la Edge Function clinova-api y PostgreSQL en el esquema clinova.

  • Modelo, migraciones y autenticación
  • Módulos y motor de sincronización
  • QA, secuencias y compilación
  • DER local y cloud

La contabilidad del nuevo rol se conserva localmente; aún no tiene sincronización cloud ni facturación tributaria.
